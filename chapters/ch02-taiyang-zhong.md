# 辨太阳病脉证并治中（太阳中 · 条文 31–127）

## Core Idea
本篇展开太阳病的完整治法谱系：麻黄汤发汗解表、葛根汤治项背强几几与太阳阳明合病、大小青龙汤治表实里热/外寒内饮、小柴胡汤开少阳枢机，并系统论述发汗/吐/下/火法误治后的种种变证与救逆——是六经方证的"主战场"。

## Frameworks Introduced
- **麻黄汤证（太阳伤寒表实，条文 35）**：头痛、发热、身疼、腰痛、骨节疼痛、恶风、无汗而喘 → 麻黄汤发汗解表。与桂枝汤（有汗）相对，"无汗用麻黄"。
- **葛根汤证（条文 31–33）**：项背强几几、无汗、恶风 → 葛根汤（桂枝汤＋葛根、麻黄）。太阳阳明合病"必自下利"用葛根汤，"但呕"用葛根加半夏汤。
- **葛根黄芩黄连汤（条文 34）**：桂枝证误下、利遂不止、喘而汗出 → 表里俱热之协热下利，清热止利。
- **大青龙汤（条文 38–39）**：脉浮紧、发热恶寒、身疼痛、不汗出而烦躁 → 表实兼里热，重剂发汗兼清。**禁忌**：脉微弱、汗出恶风者不可服，服则厥逆筋惕肉瞤（亡阳）。
- **小青龙汤（条文 40–41）**：伤寒表不解、心下有水气，干呕、发热而咳、或渴/利/噎/小便不利/喘 → 外寒内饮，温肺化饮。服汤已渴者为"寒去欲解"。
- **小柴胡汤证（条文 96）**：往来寒热、胸胁苦满、嘿嘿不欲饮食、心烦喜呕 → 少阳主方，和解枢机。**"但见一证便是，不必悉具"（条文 101）**：抓主证，不必四证俱全。
- **太阳蓄水 vs 蓄血**：
  - 蓄水（五苓散，条文 71–74）：脉浮、小便不利、微热、消渴，或水入则吐（水逆）→ 化气利水。
  - 蓄血（桃核承气汤轻证 106；抵当汤/丸重证 124–126）：少腹急结/硬满、小便自利、其人如狂/发狂 → 攻下瘀血。**鉴别枢：小便利否**——蓄水小便不利，蓄血小便自利。
- **表里先后 / 救里救表（条文 91–92）**：下利清谷不止、身疼痛 → **急当救里**（四逆汤），后救表（桂枝汤）。里虚为急时先温里。
- **发汗后变证谱系**：心下悸欲得按（桂枝甘草汤）、脐下悸欲作奔豚（苓桂甘枣汤）、心下逆满头眩身振摇（苓桂术甘汤）、汗出而喘无大热（麻杏石甘汤）、汗出不解心下悸头眩身瞤动振振欲擗地（真武汤，阳虚水泛）、身疼痛脉沉迟（桂枝新加汤）、反恶寒（芍药甘草附子汤）、烦躁（茯苓四逆汤）。
- **栀子豉汤类（虚烦，条文 76–81）**：发汗吐下后"虚烦不得眠、反复颠倒、心中懊憹" → 栀子豉汤清宣胸膈郁热；少气加甘草、呕加生姜、腹满加厚朴枳实、下后微烦加干姜。**禁**：旧微溏者不可与。
- **不可发汗之"家"（条文 83–89）**：咽喉干燥、淋家（便血）、疮家（痉）、衄家（额陷直视）、亡血家（寒栗而振）、汗家（恍惚心乱）——津血已亏者禁汗。
- **火逆诸证（条文 110–119）**：火劫/温针/灸误用 → 亡阳惊狂（桂枝去芍药加蜀漆牡蛎龙骨救逆汤）、奔豚（桂枝加桂汤）、烦躁（桂枝甘草龙骨牡蛎汤）。火法伤津耗血，"焦骨伤筋"。

## Key Concepts
- **麻黄汤**：麻黄、桂枝、杏仁、甘草——发汗解表、宣肺平喘，太阳伤寒正治。
- **葛根汤**：桂枝汤加葛根、麻黄——解肌发汗、升津舒经。
- **大青龙汤 / 小青龙汤**：一为表寒里热（烦躁），一为表寒里饮（咳喘水气）。
- **小柴胡汤**：柴胡、黄芩、人参、半夏、甘草、生姜、大枣——和解少阳。
- **五苓散**：猪苓、泽泻、白术、茯苓、桂枝——化气利水，蓄水主方。
- **抵当汤/丸**：水蛭、虻虫、桃仁、大黄——破血逐瘀，蓄血重证。
- **真武汤**：附子、茯苓、白术、芍药、生姜——温阳利水。
- **协热下利**：表热内陷而利（葛根芩连汤证）。
- **水逆**：渴欲饮水、水入则吐。
- **衄解 / 阳气重**：表实日久、阳气郁重，可借鼻衄而解。
- **战汗**：脉阴阳俱停、振栗汗出而解——正邪交争之机。

## Mental Models
- **"有汗桂枝、无汗麻黄、烦躁大青龙、水气小青龙"**：太阳表证四方选择的口诀式区分。
- **"但见一证便是"**：柴胡证只需一个主证即可用方，不必四证悉具——抓主证、舍从证。
- **"小便利否定蓄水蓄血"**：小便不利→水蓄膀胱（五苓散）；小便自利→血蓄下焦（桃核承气/抵当）。
- **"先里后表 / 急则救里"**：下利清谷（里虚寒）与表证并存时，里虚为急，先救里。
- **"津血亏者禁汗"**：咽干、淋、疮、衄、亡血、汗家皆不可发汗——护津存阴为底线。

## Anti-patterns
- **误下 / 误吐 / 火劫发汗**：表证误用下、吐、火法 → 变证：结胸、痞、下利、惊狂、奔豚、火逆。
- **大青龙汤误用于表虚**：脉微弱汗出者服之则厥逆、筋惕肉瞤、亡阳。
- **蓄血未解外即攻下**：外证未解者"尚未可攻，当先解外"，否则表邪内陷。
- **发汗过多**：叉手自冒心（心阳虚）、脐下悸（奔豚欲作）、身瞤动（阳虚水泛）。
- **栀子豉汤用于旧微溏者**：苦寒清宣伤脾阳，便溏者禁用。

## Worked Example（条文 71 · 五苓散证）
> 太阳病，发汗后，大汗出、胃中干、烦躁不得眠，欲得饮水者，少少与饮之……若脉浮、小便不利、微热、消渴者，五苓散主之。

- 鉴别：大汗后仅胃中干者，少少饮水令胃气和则愈；若脉浮 + 小便不利 + 微热 + 消渴，则是水蓄膀胱、气化不利 → 五苓散（猪苓、泽泻、白术、茯苓、桂枝），捣散，白饮和服，**多饮暖水、汗出愈**。
- **Why it works**：五苓散以猪苓、泽泻、茯苓淡渗利水，白术健脾，桂枝温阳化气——通阳化气则水行、渴止、小便自利，外证亦随之而解（表里双解）。

## Key Takeaways
1. 太阳表证四大方：有汗桂枝、无汗麻黄、烦躁大青龙、水气小青龙。
2. 小柴胡汤"但见一证便是"，不必悉具——辨方证抓主证。
3. 蓄水与蓄血的分水岭在"小便自利与否"。
4. 表里同病，里虚寒（下利清谷）为急，先救里后救表。
5. 津血亏虚者（咽干、淋、疮、衄、亡血、汗家）禁发汗。
6. 发汗、吐、下、火法皆有度，误用则生变证——救逆回到"随证治之"。
