# 辨太阳病脉证并治下（太阳下 · 条文 128–178）

## Core Idea
本篇专论太阳病误下后的两大变证谱系——**结胸**与**痞证**，兼及脏结、悬饮、热入血室、少阳兼证、风湿、气分热（白虎类）与心动悸脉结代（炙甘草汤），是"误下辨治"最集中的一章。

## Frameworks Introduced
- **结胸 vs 痞（条文 131）**：**病发于阳而误下 → 热入作结胸；病发于阴而误下 → 作痞**。结胸按之痛（心下硬满而痛不可近），痞则"但满而不痛、按之自濡"。这是误下两条路径的总纲。
- **结胸辨证（分轻重与虚实）**：
  - 大结胸（大陷胸汤/丸，条文 134–137）：水热互结，心下痛、按之石硬、从心下至少腹硬满而痛不可近 → 泻热逐水。
  - 小结胸（小陷胸汤，条文 138）：正在心下、按之则痛、脉浮滑 → 清热涤痰（黄连、半夏、栝蒌实）。
  - 寒实结胸（三物白散，条文 141）：无热证者 → 巴豆温下寒实。
  - 脏结（条文 129–130、167）：如结胸状、时时下利、舌上白苔滑、无阳证 → **不可攻，难治/死**。
- **痞证·泻心汤类（半夏/生姜/甘草泻心汤，条文 149、157、158）**：寒热错杂、胃虚气逆，心下痞硬。三方同源于理中、寒热并用、辛开苦降：
  - 半夏泻心汤——呕而发热柴胡证误下、心下满而不痛（痰气痞，基础方）。
  - 生姜泻心汤——干噫食臭、胁下有水气、腹中雷鸣下利（水热互结）。
  - 甘草泻心汤——下利日数十行、谷不化、胃中虚、客气上逆（虚痞，重用甘草）。
- **热痞（大黄黄连泻心汤，条文 154）**：心下痞、按之濡、脉关上浮 → 泻热消痞（麻沸汤渍取气）。兼恶寒汗出者，附子泻心汤（热痞兼表阳虚）。
- **痞证层次（条文 152–164）**：悬饮十枣汤（心下痞硬满引胁下痛、汗出短气——芫花甘遂大戟，表解乃可攻）；痰气痞旋覆代赭汤（噫气不除）；协热利桂枝人参汤（表里不解）；下焦滑脱赤石脂禹余粮汤；**先解表后攻痞**（表不解不可攻痞，桂枝汤解表、大黄黄连泻心汤攻痞）。
- **热入血室（条文 143–145）**：妇人经水适来适断，胸胁下满如结胸状、谵语、暮则如见鬼状 → 刺期门（随实而取）或小柴胡汤。**禁犯胃气及上二焦**。
- **少阳兼证**：柴胡桂枝汤（发热微恶寒、肢节烦痛、心下支结——少阳兼表）；柴胡桂枝干姜汤（胸胁满微结、小便不利、渴而不呕、但头汗出——少阳兼水饮/阳虚）；阳微结（头汗出、手足冷、心下满、大便硬、脉细——半在里半在外，与小柴胡汤）。
- **气分热（白虎汤类，条文 168–170、176）**：热结在里、表里俱热、大渴、舌上干燥而烦 → 白虎加人参汤。**禁忌**：表不解、脉浮发热无汗者不可与白虎；立秋后/亡血虚家慎用。
- **风湿（条文 174–175）**：桂枝附子汤（风湿相搏、身体疼烦不能自转侧）；去桂加白术汤（大便硬小便自利）；甘草附子汤（骨节疼烦掣痛、近之痛剧、汗出短气）。
- **心动悸脉结代（炙甘草汤，条文 177–178）**：脉结代、心动悸 → 炙甘草汤（复脉汤）益气养血、通阳复脉；并定义结脉、代脉。

## Key Concepts
- **结胸**：水热互结于心下/胸胁，按之硬痛。
- **痞证**：寒热错杂、气机痞塞，满而不痛、按之自濡。
- **脏结**：脏气衰微、阴寒凝结，不可攻。
- **悬饮**：水饮停于胸胁，咳唾引痛（十枣汤）。
- **热入血室**：经期血海空虚、热邪乘虚内陷。
- **辛开苦降**：泻心汤以半夏、干姜辛开，黄芩、黄连苦降，寒热并调。
- **协热利**：表证误下、表热内陷而下利。
- **结脉 / 代脉**：脉缓时一止复来为结；动而中止、不能自还者为代——代脉难治。

## Mental Models
- **"误下两变：发于阳则结胸，发于阴则痞"**：判断误下后果的定性规则。
- **"结胸按之痛、痞满而不痛"**：一实（水热有形）一虚（气痞无形），以"痛与不痛、濡与硬"为辨。
- **"表解乃可攻里"**：十枣汤、攻痞皆须表解——表里先后之法的延续。
- **"热入血室禁犯胃气"**：病在血分，不可误用汗吐下伤胃气，可自愈或刺期门。
- **"表不解不可与白虎"**：白虎甘寒，表邪未解误用则冰伏其邪。

## Anti-patterns
- **结胸证脉浮大而下之**：脉浮大（邪未结实）误下则死。
- **结胸证悉具而烦躁**：正不胜邪，死候。
- **脏结误攻**：无阳证、舌苔滑者攻之则危。
- **痞证误再下**：见心下痞误以为结热未尽而复下，痞益甚（胃虚客气上逆，非结热）。
- **悬饮表未解而攻**：十枣汤峻下逐水，必先解表。
- **白虎误用于表不解/里虚寒**：立秋后、亡血虚家服之则呕利腹痛。

## Worked Example（条文 149 · 结胸与痞的分水岭）
> 伤寒五六日，呕而发热者，柴胡汤证具，而以他药下之……若心下满而硬痛者，此为结胸也，大陷胸汤主之；但满而不痛者，此为痞，柴胡不中与之，宜半夏泻心汤。

- 同一"误下"起点，结局二分：心下**满而硬痛**＝有形水热结聚 → 大陷胸汤（大黄、芒硝、甘遂）泻热逐水；**满而不痛**＝无形气痞 → 半夏泻心汤（半夏、黄芩、干姜、人参、甘草、黄连、大枣）辛开苦降、消痞和中。
- **Why it works**：以"痛"与"濡"辨有形无形——有痛为水热实邪，无痛为气机壅滞，治法一峻下、一和调，截然两途。

## Key Takeaways
1. 误下两变：发于阳成结胸，发于阴成痞——先定性。
2. 结胸辨虚实寒热：大陷胸（水热）/小陷胸（痰热）/三物白散（寒实）/脏结（禁攻）。
3. 痞证核心是辛开苦降、寒热并用——半夏泻心汤为母方。
4. "按之痛与不痛"是结胸与痞的鉴别枢。
5. 攻里（十枣、攻痞）必先解表。
6. 表不解不可与白虎；误下成痞不可再下。
