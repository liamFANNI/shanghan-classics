# 辨霍乱病脉证并治（霍乱 · 条文 382–391）

## Core Idea
霍乱以"呕吐而利"为主证，属脾胃气机暴乱、清浊相干之证。本篇据寒热分治——热多饮水者五苓散，寒多不用水者理中丸，并示吐利伤阳亡液时的回阳救逆之法。

## Frameworks Introduced
- **霍乱定义（条文 382–383）**：呕吐而利为霍乱；兼发热、头痛、身疼、恶寒者为霍乱表证。
- **分利寒热（条文 386）**：霍乱头痛发热身疼痛——**热多欲饮水者**五苓散（分利水湿、兼解表）；**寒多不用水者**理中丸（温中散寒、健脾止利）。以"欲饮水与否"分寒热。
- **理中丸（条文 386，附汤加减法）**：人参、干姜、甘草、白术——温中焦、理脾胃。加减：脐上筑去术加桂、吐多去术加生姜、下多用术、悸加茯苓、渴加术、痛加人参、寒加干姜、腹满去术加附子；服后饮热粥温之。
- **回阳救逆（条文 385、388–390）**：
  - 四逆加人参汤——恶寒脉微、利止亡血（回阳益气生津）。
  - 四逆汤——吐利汗出、发热恶寒、四肢拘急、手足厥冷；或下利清谷、内寒外热、脉微欲绝。
  - 通脉四逆加猪胆汁汤——吐已下断、汗出而厥、四肢拘急、脉微欲绝（阴竭阳脱，反佐以胆汁）。
- **吐利后调治（条文 387、391）**：吐利止而身痛不休 → 桂枝汤小和之（解外）；吐利发汗后脉平、小烦 → 新虚不胜谷气，勿再药。

## Key Concepts
- **霍乱**：呕吐而利并作，清浊相干、中焦气乱。
- **理中丸 / 理中汤**：温中散寒主方（后世"理中丸"之祖）。
- **四逆加人参汤**：回阳兼益气生津（利止亡血）。
- **通脉四逆加猪胆汁汤**：阴寒格拒、阴竭阳脱之救逆，反佐法。
- **新虚不胜谷气**：病后脾胃尚弱，过食则微烦。

## Mental Models
- **"热多欲饮五苓、寒多不饮理中"**：霍乱吐利以口渴与否分寒热——渴者为湿/热偏胜，不渴者为寒湿内盛。
- **"吐利伤阳即回阳"**：吐利不止、厥逆脉微，即投四逆辈回阳救逆，不必待少阴全证。
- **"吐利止、身痛则小和其外"**：里气初复而表未解者，用桂枝汤轻剂和解，勿重发汗。

## Anti-patterns
- **寒霍乱误用苦寒清利**：寒多不用水者误投寒凉，中阳更败。
- **吐利后重发汗**：津阳已伤，再汗则亡阳脱液。
- **病后强食**：新虚不胜谷气，过食致微烦。

## Worked Example（条文 386 · 霍乱分利寒热）
> 霍乱，头痛、发热、身疼痛、热多欲饮水者，五苓散主之；寒多不用水者，理中丸主之。

- 同为霍乱吐利兼表证，以渴否分径：渴欲饮水（热多、水液偏渗）→ 五苓散化气利水、表里分消；口不渴（寒多、中阳不振）→ 理中丸温中散寒。
- **Why it works**：五苓散通阳利水使水湿归常道、吐利自止；理中丸温补中焦、升清降浊而止利——一以"分利"治水，一以"温中"治寒，异病同证不同治。

## Key Takeaways
1. 霍乱＝呕吐而利并作，治在脾胃。
2. 渴（热多）用五苓散，不渴（寒多）用理中丸。
3. 吐利伤阳厥逆者，四逆汤/四逆加人参汤/通脉四逆加猪胆汁汤回阳救逆。
4. 吐利止而身痛，桂枝汤小和其外。
5. 病后脾胃虚弱，须节饮食（新虚不胜谷气）。
