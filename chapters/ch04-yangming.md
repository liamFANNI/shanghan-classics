# 辨阳明病脉证并治（阳明 · 条文 179–262）

## Core Idea
阳明病为里热实证，提纲"胃家实"，外证"身热、汗自出、不恶寒反恶热"。治以清（白虎类）与下（三承气汤）两法为主线，兼论发黄、脾约、蓄血、急下存阴——是"里实热证"辨治的巅峰。

## Frameworks Introduced
- **阳明病提纲（条文 180、182）**：胃家实 + 身热、汗自出、不恶寒反恶热、脉大。阳明居中主土，"万物所归，无所复传"。
- **阳明三型（条文 179）**：太阳阳明（脾约）、正阳阳明（胃家实）、少阳阳明（发汗利小便后胃中燥、大便难）。成因总归于"亡津液、胃中干燥"。
- **经证 vs 腑证**：
  - 经证（无形之热）：大热、大渴、大汗、脉洪大 → 白虎汤/白虎加人参汤清热。
  - 腑证（有形燥屎）：潮热、谵语、腹满硬痛、手足濈然汗出 → 承气汤攻下。
- **三承气汤（攻下梯度，条文 207–215）**：
  - 调胃承气汤——不吐不下、心烦、蒸蒸发热，和胃气（缓下，以甘草缓之）。
  - 小承气汤——腹大满不通、微和胃气（轻下，去芒硝）。
  - 大承气汤——潮热、谵语、大便硬、手足濈然汗出、绕脐痛（峻下，硝黄枳朴俱全）。
  - **试燥屎法（条文 209）**：少与小承气汤，服后"转矢气"者有燥屎可攻；不转矢气者初硬后溏，不可攻。
- **急下存阴（条文 252–254）**：目中不了了、睛不和；发热汗多；发汗不解腹满痛——三急下证，皆大承气汤峻下以急存阴液。
- **阳明发黄（条文 236、260–262）**：瘀热在里、身黄如橘子色、小便不利 → 茵陈蒿汤（茵陈、栀子、大黄，黄从小便去）；身黄发热栀子柏皮汤；表证兼瘀热麻黄连轺赤小豆汤。**寒湿发黄（条文 259）**：不可下，"于寒湿中求之"。
- **脾约（条文 247）**：趺阳脉浮而涩、小便数、大便硬 → 麻子仁丸润下缓通。
- **津液内竭导法（条文 233）**：自汗出、小便自利、津液内竭而大便硬 → 蜜煎导、土瓜根、猪胆汁导下，不攻。
- **辨谵语虚实（条文 210–212）**：实则谵语、虚则郑声（重语）；直视、谵语、喘满者死；循衣摸床、微喘直视，脉弦者生、涩者死。

## Key Concepts
- **胃家实**：阳明提纲，胃肠燥实、热实。
- **正阳阳明 / 太阳阳明 / 少阳阳明**：阳明病三种来路。
- **潮热**：日晡所发热，阳明腑实标志。
- **濈然汗出**：手足/遍身持续微汗，大便已硬之征。
- **燥屎**：肠中干结之粪块，攻下依据。
- **转矢气**：服小承气汤后排气，验燥屎之法。
- **谵语 / 郑声**：实热扰神为谵语，虚证重复低语为郑声。
- **循衣摸床**：阳明热极、神识昏愦之危候。
- **脾约**：胃强脾弱、津液偏渗膀胱而便秘。

## Mental Models
- **"清经证、下腑证"**：无形热用白虎清，有形燥屎用承气下——阳明两大治法分界。
- **"三承气梯度"**：调胃（和）→ 小承气（轻下）→ 大承气（峻下），据燥实轻重选方。
- **"转矢气验燥屎"**：不攻之前先试探，避免误攻初硬后溏。
- **"急下存阴"**：津液将竭（目睛不和、汗多、腹满痛）时，峻下即是保阴。
- **"亡津液则转阳明"**：发汗、利小便过则胃燥便难——护津是防阳明之要。

## Anti-patterns
- **呕多、心下硬满、面合色赤而攻下**：病势在上、邪未入腑，攻之则利不止或发黄。
- **初硬后溏误攻**：不转矢气、小便少者攻之必胀满不能食、下利。
- **表未解而攻下**：脉浮、微恶寒者当先解表（桂枝汤/麻黄汤）。
- **汗多而渴与猪苓汤**：汗多胃中燥，再利小便则更伤津液。
- **寒湿发黄误下**：身黄因寒湿者不可下，当温化。
- **谵语脉短/涩**：亡阳、津竭之谵语，脉短/涩为死候，不可再攻。

## Worked Example（条文 208 · 三承气汤选择）
> 阳明病，脉迟……腹满而喘，有潮热者，此外欲解，可攻里也。手足濈然汗出者，此大便已硬也，大承气汤主之；若汗多、微发热恶寒者，外未解也……其热不潮，未可与承气汤；若腹大满不通者，可与小承气汤，微和胃气，勿令至大泄下。

- 决策链：有潮热 + 手足濈然汗出（大便已硬）→ 大承气汤峻下；热不潮、仅腹大满不通 → 小承气汤微和胃气；汗多微恶寒（表未解）→ 不可攻，先解表。
- 大承气汤：大黄四两、厚朴半斤、枳实五枚、芒硝三合，先煮枳朴后内硝黄，"得下，余勿服"。
- **Why it works**：以"潮热、濈然汗出"判断燥屎已结，据结实程度选择攻下力度，表不解则禁下——攻下三要素（燥屎证、无表证、胃气未虚）齐备方用大承气。

## Key Takeaways
1. 阳明病 = 里热实，"胃家实"+"身热汗出不恶寒反恶热"为纲。
2. 清法（白虎）治无形经热，下法（承气）治有形燥屎。
3. 三承气汤按"和、轻下、峻下"梯度选用，攻前以转矢气验燥屎。
4. "急下存阴"——津液将竭时峻下即保阴。
5. 攻下三禁：呕多、心下硬满、面合色赤；并禁表未解与寒湿发黄误下。
6. 阳明发黄分湿热（茵陈蒿汤类）与寒湿（温化），不可混治。
