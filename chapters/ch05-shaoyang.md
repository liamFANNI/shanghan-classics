# 辨少阳病脉证并治（少阳 · 条文 263–272）

## Core Idea
少阳病居半表半里，枢机不利。提纲"口苦、咽干、目眩"，主方小柴胡汤和解枢机。治禁"汗、吐、下"三法——少阳为表里之枢，只可和解，不可发汗、涌吐、攻下。

## Frameworks Introduced
- **少阳病提纲（条文 263）**：口苦、咽干、目眩——胆热上炎、枢机不利之象。
- **少阳半表半里**：邪在表里之间，既非太阳之表、亦非阳明之里，故往来寒热、胸胁苦满、嘿嘿不欲饮食、心烦喜呕（详 Ch02 条文 96）。
- **和解法（小柴胡汤，条文 266）**：太阳病转入少阳，胁下硬满、干呕不能食、往来寒热 → 小柴胡汤和解。柴胡、黄芩清透少阳，人参、甘草、大枣扶正，半夏、生姜和胃降逆。
- **少阳三禁（条文 264–265）**：**禁吐下**（吐下则悸而惊）、**禁发汗**（发汗则谵语，属胃）。少阳只可和解。
- **坏病原则（条文 267）**：已吐下发汗温针、柴胡证罢而谵语者，为坏病——"知犯何逆，以法治之"。
- **传变之辨（条文 269–270）**：无大热而躁烦为"阳去入阴"；三阳尽、三阴当受邪，能食不呕则三阴不受邪。

## Key Concepts
- **少阳病**：半表半里之证，胆与三焦气机不利。
- **口苦咽干目眩**：少阳提纲三联。
- **往来寒热**：邪正分争于半表半里，休作有时。
- **胸胁苦满**：邪结胁下（少阳经所过）。
- **和解**：扶正透邪、调和枢机，非汗非下。

## Mental Models
- **"半表半里只和解"**：既不在表（不可汗）、又未入里（不可下），唯小柴胡汤枢转。
- **"口苦咽干目眩 = 少阳"**：见此三联即归少阳，不必诸证悉具。
- **"阳去入阴"**：躁烦而无大热，提示病由阳经转入阴经（加重）。

## Anti-patterns
- **少阳误汗**：发汗则谵语、烦而悸（津伤胃燥，病转阳明）。
- **少阳误吐下**：吐下则悸而惊（伤正扰神）。
- **误治成坏病仍守柴胡**：柴胡证罢即须"随证治之"，不可执方不变。

## Worked Example（条文 266 · 太阳转少阳）
> 本太阳病不解，转入少阳者，胁下硬满、干呕不能食、往来寒热……与小柴胡汤。

- 太阳病迁延不解，邪入半表半里：胁下硬满（邪结胁下）、往来寒热（正邪分争）、干呕不能食（胃气上逆）→ 小柴胡汤（柴胡八两为君，黄芩清胆，参草枣扶正，夏姜和胃），去滓再煎以和之。
- **Why it works**：柴胡升清透邪、黄芩降浊清热，一升一降枢转少阳；参草枣补正以防邪深入，全方"上焦得通，津液得下，胃气因和，身濈然汗出而解"。

## Key Takeaways
1. 少阳提纲"口苦、咽干、目眩"，主方小柴胡汤。
2. 少阳半表半里，禁汗、吐、下，唯和解一法。
3. 往来寒热、胸胁苦满是少阳独有标志。
4. 误治成坏病，即弃柴胡、随证治之。
5. 少阳传变：阳去入阴则入三阴经。
