# 辨厥阴病脉证并治（厥阴 · 条文 326–381）

## Core Idea
厥阴病为六经之末、寒热错杂之证。提纲"消渴、气上撞心、心中疼热、饥而不欲食、食则吐蛔"——上热下寒、阴阳气不相顺接。治以寒热并用（乌梅丸为纲），兼论厥热胜复、诸厥辨治与下利。

## Frameworks Introduced
- **厥阴病提纲（条文 326）**：消渴、气上撞心、心中疼热、饥而不欲食、食则吐蛔——上热下寒、肝木横逆。**禁下**：下之利不止。
- **厥的定义（条文 337）**："凡厥者，阴阳气不相顺接，便为厥。厥者，手足逆冷者是也。"——一切厥冷的总纲。
- **厥热胜复（条文 331–336）**：厥阴病独特的寒热往复——先厥后发热、下利自止；**"厥深热亦深，厥微热亦微"**；以厥与热的日数对比判预后（厥少热多当愈，寒多热少为进）。
- **除中（条文 332–333）**：厥利本当不能食，反能食者为"除中"（胃气败绝之回光返照），必死。
- **脏厥 vs 蛔厥（乌梅丸，条文 338）**：
  - 脏厥：脉微而厥、肤冷、躁无暂安时——阳衰危候。
  - 蛔厥：静而复时烦、得食而呕、常自吐蛔——乌梅丸（寒热并用、酸苦辛甘复法）主之，又主久利。
- **诸厥辨治**：
  - 热厥（条文 350）：脉滑而厥、里有热 → 白虎汤清热（"厥应下之/清之"）。
  - 血虚寒厥（条文 351–352）：手足厥寒、脉细欲绝 → 当归四逆汤养血温经；内有久寒加吴茱萸生姜。
  - 阳虚寒厥（条文 353–354）：大汗、大下利而厥冷 → 四逆汤。
  - 水厥（条文 356）：厥而心下悸，先治水 → 茯苓甘草汤。
  - 痰厥（条文 355）：手足厥冷、脉乍紧、心下满而烦 → 瓜蒂散吐之。
- **上热下寒（寒格）**：干姜黄芩黄连人参汤（条文 359，食入口即吐——寒格）；麻黄升麻汤（条文 357，大下后寸脉沉迟、手足厥逆、喉咽不利唾脓血——上热下寒、正虚邪陷之复杂证）。
- **厥阴下利辨治**：
  - 热利下重（条文 371、373）：白头翁汤（白头翁、黄柏、黄连、秦皮）清肝泄热、凉血止利。
  - 寒利（条文 370）：下利清谷、里寒外热、汗出而厥 → 通脉四逆汤。
  - 燥屎下利（条文 374）：下利谵语 → 小承气汤。
  - 虚烦（条文 375）：下利后更烦、按之心下濡 → 栀子豉汤。
  - 先温里后攻表（条文 372）：下利腹胀满、身疼痛 → 先四逆汤温里、后桂枝汤攻表。

## Key Concepts
- **厥阴病**：寒热错杂、阴阳气不相顺接之证。
- **厥**：手足逆冷，阴阳气不相顺接。
- **厥热胜复**：厥阴病寒与热交替、以日数消长判预后。
- **除中**：胃气将绝、中气败而反能食之死候。
- **脏厥 / 蛔厥**：阳衰之厥与蛔扰之厥的鉴别。
- **寒格**：下寒拒药/拒食，食入口即吐。
- **热利下重**：肝经湿热下迫、里急后重。

## Mental Models
- **"寒热并用治厥阴"**：乌梅丸酸苦辛甘、附子桂枝与黄连黄柏同用——厥阴寒热错杂当寒热并调，非纯温纯清所能。
- **"厥深热亦深"**：厥冷越重，内闭之热越深——热厥不可误作寒厥温之。
- **"先温里后攻表"**：下利清谷兼表证，里虚寒为急，先温里（四逆汤）后解表（桂枝汤）。
- **"手足逆冷须辨寒热虚实"**：热厥（脉滑）、寒厥（脉微细）、血虚厥（脉细欲绝）、水厥（心下悸）、痰厥（脉乍紧满而烦）——以脉证定因。
- **"反能食者恐除中"**：危重下利见食欲异常增进，当警惕胃气败绝。

## Anti-patterns
- **诸四逆厥者误下**：厥证、虚家皆不可下，下之危殆。
- **脉迟寒证误用黄芩汤清其热**：寒者更寒，可致除中而死。
- **厥阴病误下**：下之利不止。
- **下利清谷误攻表**：汗出必胀满。
- **热利误作寒利温补**：白头翁汤证误投温涩，热邪愈炽。

## Worked Example（条文 338 · 乌梅丸证）
> 蛔厥者……静而复时烦者，此为脏寒，蛔上入其膈，故烦，须臾复止；得食而呕，又烦者，蛔闻食臭出，其人常自吐蛔。蛔厥者，乌梅丸主之，又主久利。

- 方：乌梅三百枚（苦酒渍）、细辛、干姜、黄连、当归、附子、蜀椒、桂枝、人参、黄柏各六两/四两/十六两不等，蜜丸。寒热并投、酸收蛔、辛伏蛔、苦下蛔。
- **Why it works**：厥阴上热下寒、蛔虫扰动——乌梅之酸安蛔，蜀椒、细辛、干姜、附子之辛温散下寒，黄连、黄柏之苦寒清上热，人参、当归、桂枝气血双补、调和阴阳。一方而寒热并用、补泻兼施，为厥阴病代表方。

## Key Takeaways
1. 厥阴提纲"消渴、气上撞心、心中疼热、饥而不欲食、食则吐蛔"——上热下寒。
2. 厥＝阴阳气不相顺接（手足逆冷），须辨寒热虚实（热厥/寒厥/血虚厥/水厥/痰厥）。
3. 乌梅丸是厥阴寒热并用的代表方，兼治蛔厥与久利。
4. "厥深热亦深"——热厥越厥越热，忌误作寒证。
5. 除中（厥利反能食）为胃气败绝死候。
6. 厥阴下利分寒（通脉四逆/四逆）热（白头翁汤）燥屎（小承气）虚烦（栀子豉）。
