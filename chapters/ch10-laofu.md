# 辨阴阳易瘥后劳复病脉证并治（阴阳易差后劳复 · 条文 392–398）

## Core Idea
本篇论大病初愈后的两类问题——阴阳易（房劳复感）与劳复（过劳、食复致热复发），并给出差后调理方：枳实栀子豉汤、小柴胡汤、牡蛎泽泻散、理中丸、竹叶石膏汤，最后以"损谷则愈"收束全书。

## Frameworks Introduced
- **阴阳易（条文 392）**：伤寒阴阳易，身体重、少气、少腹里急、热上冲胸、头重不欲举、眼中生花、膝胫拘急 → 烧裈散（后世有争议，象征性方）。病机为病后余邪未尽、复感房劳。
- **劳复（条文 393）**：大病瘥后劳复 → 枳实栀子豉汤（枳实、栀子、香豉）清热除烦、宽中散滞；若有宿食，内大黄。
- **瘥后更发热（条文 394）**：小柴胡汤主之；脉浮者以汗解之，脉沉实者以下解之——据脉定汗、和、下三法。
- **差后水气（条文 395）**：腰以下有水气 → 牡蛎泽泻散（牡蛎、泽泻、蜀漆、葶苈子、商陆根、海藻、栝蒌根）逐水消肿。
- **差后喜唾（条文 396）**：胸上有寒、喜唾久不了了 → 理中丸温之。
- **气阴两虚（条文 397）**：伤寒解后、虚羸少气、气逆欲吐 → 竹叶石膏汤（竹叶、石膏、半夏、麦门冬、人参、甘草、粳米）清热益气养阴。
- **损谷则愈（条文 398）**：脉已解而日暮微烦——新瘥脾胃尚弱、强与谷不能消，减食即愈。

## Key Concepts
- **阴阳易**：病后房劳复感，余邪乘虚相染。
- **劳复**：大病初愈因过劳而复发热。
- **食复 / 损谷**：过食致烦，节食（损谷）即愈。
- **枳实栀子豉汤**：劳复、食复清热除烦。
- **竹叶石膏汤**：差后气阴两虚、余热未清。
- **牡蛎泽泻散**：差后水气（腰以下肿）。

## Mental Models
- **"差后重在调养"**：病已解而脾胃未复，治宜轻剂调之，忌峻攻峻补。
- **"损谷则愈"**：新瘥微烦多因强食不消，节食即是治。
- **"据脉定差后治法"**：更发热脉浮者汗解、脉沉实者下解、脉弦/往来寒热者和小柴胡。
- **"气阴两伤则竹叶石膏"**：解后虚羸少气、气逆欲吐，清热与益气养阴并施。

## Anti-patterns
- **差后峻补 / 过食**：脾胃尚弱，峻补滋腻或强食皆致复病（食复、微烦）。
- **劳复误作表证重汗**：虚人复热，重汗伤正。
- **差后水气误用峻下逐水（不分虚实）**：牡蛎泽泻散用于实邪水气，虚者当辨。

## Worked Example（条文 397 · 竹叶石膏汤证）
> 伤寒解后，虚羸少气、气逆欲吐，竹叶石膏汤主之。

- 大病后余热未清、气阴两伤：虚羸（形体消瘦）、少气（气虚）、气逆欲吐（胃虚气逆）→ 竹叶石膏汤（竹叶、石膏清余热，麦门冬养阴，人参、甘草、粳米益气和中，半夏降逆止呕）。
- **Why it works**：以石膏、竹叶清透余热，配麦冬、人参、粳米、甘草益气生津，半夏和胃降逆——清补并施，恰合"虚人余热"之机，是伤寒差后调理的代表方。

## Key Takeaways
1. 阴阳易、劳复是病后两大复发途径，重在调养防复。
2. 劳复/食复用枳实栀子豉汤，宿食加大黄。
3. 差后更发热据脉分治：浮者汗、沉实者下、余者小柴胡和之。
4. 虚羸少气、气逆欲吐用竹叶石膏汤（清补并施）。
5. 新瘥微烦多因强食，"损谷则愈"。
