# 辨少阴病脉证并治（少阴 · 条文 281–325）

## Core Idea
少阴病属心肾，为六经危重阶段。提纲"脉微细、但欲寐"——心肾阳衰（或阴亏）之象。少阴有**寒化**（阳虚，回阳救逆）与**热化**（阴亏火旺，育阴清热）两途，水火为病之枢。

## Frameworks Introduced
- **少阴病提纲（条文 281）**：脉微细、但欲寐——阳气衰微、精神萎靡的总纲。
- **寒化 vs 热化**：
  - 寒化（阳虚）：下利清谷、手足厥逆、恶寒踡卧 → 四逆汤/通脉四逆汤/白通汤/真武汤/附子汤温阳救逆。
  - 热化（阴亏火旺）：心中烦不得卧 → 黄连阿胶汤；下利咳呕渴、心烦不得眠 → 猪苓汤（育阴利水清热）。
- **太少两感（条文 301–302）**：少阴病始得之、反发热、脉沉 → 麻黄细辛附子汤温阳解表；二三日无证者麻黄附子甘草汤微发汗。
- **阴盛格阳 / 戴阳（条文 315、317）**：
  - 通脉四逆汤——下利清谷、里寒外热、手足厥逆、脉微欲绝、身反不恶寒、面色赤（阴盛格阳于外/上）。
  - 白通汤（葱白、干姜、附子）通阳破阴；下利不止、厥逆无脉、干呕烦者白通加猪胆汁汤（**反佐**以破格拒）。**"脉暴出者死，微续者生"**——阳回须渐复，暴出为虚阳外脱。
- **少阴咽痛（条文 310–313）**：猪肤汤（阴虚咽痛）、甘草汤/桔梗汤（客热咽痛）、苦酒汤（咽伤生疮声不出）、半夏散及汤（寒客咽痛）。
- **少阴下利便脓血（条文 306–308）**：桃花汤（赤石脂、干姜、粳米）温涩固脱。
- **少阴三急下（条文 320–322）**：口燥咽干；自利清水色纯青、心下必痛；腹胀不大便 → 大承气汤急下存阴（少阴热化成实，与阳明急下相对）。
- **四逆散（条文 318）**：四逆（手足逆冷）而咳、悸、小便不利、腹中痛、泄利下重 → 柴胡、枳实、芍药、甘草，**疏肝解郁、透达阳郁**——与四逆汤（阳虚）相对，此属"阳郁不达"之四逆。
- **少阴预后（条文 287–300）**：可治（利自止、手足温；恶寒踡而时自烦欲去衣被）、欲解（脉紧去、手足反温）、死证（吐利躁烦四逆、息高、下利止而头眩自冒、脉不至不烦而躁、复烦躁不得卧寐）。

## Key Concepts
- **少阴病**：心肾虚衰之证，水火两途。
- **但欲寐**：精神萎靡、似睡非睡，阳虚之征。
- **寒化 / 热化**：少阴的两大转归。
- **戴阳**：下焦阴寒格阳于上，面赤如妆。
- **格拒 / 反佐**：阴寒盛极拒药不入，以猪胆汁、人尿咸寒反佐引导。
- **桃花汤**：温中涩肠止脓血。
- **四逆散**：疏肝透郁治"阳郁"之四逆。

## Mental Models
- **"少阴寒热两途"**：阳虚则寒化（四逆辈），阴亏则热化（黄连阿胶/猪苓汤）——同属少阴，一温一清。
- **"脉微细、但欲寐 = 少阴"**：见此即思心肾，不拘于寒化热化。
- **"回阳须渐、暴出者死"**：服白通辈后脉微续为佳，脉暴出为虚阳外越之危。
- **"四逆有两义"**：阳虚不温之四逆（四逆汤）与阳郁不达之四逆（四逆散），辨以脉证。
- **"少阴三急下"**：少阴热化、水竭成实，急下以存阴——与阳明急下互参。

## Anti-patterns
- **少阴误汗**：脉微、脉细沉数皆不可发汗，强发则亡阳动血（下厥上竭）。
- **少阴误下**：尺脉弱涩、阳虚者不可下。
- **少阴误火**：被火气劫则咳而下利、谵语、小便难。
- **四逆证误用四逆散（反之亦然）**：阳虚与阳郁不分，治法相悖。

## Worked Example（条文 301 · 太少两感）
> 少阴病始得之，反发热、脉沉者，麻黄细辛附子汤主之。

- 少阴本应无热、脉微细，今"反发热、脉沉"——表有寒（发热）而里阳已虚（脉沉），太少两感。麻黄细辛附子汤（麻黄二两、细辛二两、附子一枚炮）温阳与解表并施。
- **Why it works**：麻黄发太阳之表，附子温少阴之阳，细辛内通少阴、外达太阳——表里同治，既解表邪又不伤已虚之阳。若过二三日无里证，则易麻黄附子甘草汤微发汗以缓之。

## Key Takeaways
1. 少阴提纲"脉微细、但欲寐"，心肾虚衰之危候。
2. 少阴分寒化（温阳救逆）与热化（育阴清热）两途。
3. 阴盛格阳用通脉四逆汤、白通（加猪胆汁）汤，以反佐破格拒。
4. "脉暴出者死、微续者生"——回阳须渐复。
5. 少阴咽痛、便脓血、水气、阳郁各设专方（猪肤汤、桃花汤、真武汤、四逆散）。
6. 少阴三急下（口燥咽干、下利清水、腹胀不大便）用大承气汤急下存阴。
