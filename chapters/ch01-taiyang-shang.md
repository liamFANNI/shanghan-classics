# 辨太阳病脉证并治上（太阳上 · 条文 1–30）

## Core Idea
太阳病是外感热病的最初阶段（表证），提纲为"脉浮、头项强痛而恶寒"。本篇确立太阳病纲领、中风与伤寒的鉴别，并以桂枝汤为"群方之首"，示范调和营卫、解肌发汗的治法，以及误治后的救逆原则。

## Frameworks Introduced
- **太阳病提纲（Taiyang outline）**：脉浮、头项强痛而恶寒 → 这是识别表证的总纲，凡见此三联即属太阳病范畴。
  - When to use：判断病邪尚在肌表、未入里的首要标准。
  - How：见浮脉 + 头项强痛 + 恶寒，先定位"表"，再辨虚实、寒热。
- **中风与伤寒鉴别（中风/伤寒，表虚/表实）**：
  - 中风（表虚）：发热、汗出、恶风、脉缓 → 桂枝汤。
  - 伤寒（表实）：或已发热或未发热，必恶寒、体痛、呕逆、脉阴阳俱紧 → 麻黄汤（方见太阳中）。
  - How：**有汗 vs 无汗、脉缓 vs 脉紧**是分水岭。
- **传经（transmission，传与不传）**：脉静为不传；颇欲吐、躁烦、脉数急者为传。二三日阳明、少阳证不见者为不传。
- **"观其脉证，知犯何逆，随证治之"（条文 16）**：全书的辨证论治总纲——不拘于原方原病，而据当下的脉证判断误治之"逆"，随证施治。坏病（误治后变证）时桂枝汤不可再用。
- **桂枝汤及其类方（Guizhi Tang formula family）**：调和营卫、解肌发汗。类方化裁：桂枝加葛根汤（项背强几几反汗出恶风）、桂枝加附子汤（汗漏不止、小便难、四肢微急）、桂枝去芍药汤（下后脉促胸满）、桂枝去芍药加附子汤（微恶寒）、桂枝麻黄各半汤（如疟状、面有热色身痒）、桂枝二麻黄一汤、桂枝二越婢一汤（热多寒少脉微弱）、桂枝去桂加茯苓白术汤（心下满微痛小便不利）。
- **救逆（误治后的补救，条文 29）**：误汗后厥逆咽干烦躁吐逆 → 先甘草干姜汤复阳；厥愈足温 → 芍药甘草汤伸脚；胃气不和谵语 → 少与调胃承气汤；重发汗复加烧针 → 四逆汤。此为"随证治之"的标准示范。

## Key Concepts
- **太阳病**：外感初期表证，脉浮头项强痛恶寒。
- **中风**：太阳表虚证，汗出恶风脉缓。
- **伤寒**：太阳表实证，无汗恶寒脉紧（本篇之义，与广义"伤寒"书名有别）。
- **温病/风温**：发热而渴不恶寒，与伤寒之恶寒鉴别（后为温病学派立论之源）。
- **坏病**：误汗/吐/下/温针后不愈的变证，须随证治之而非仍用原方。
- **营卫**：桂枝汤调和之对象——阳浮（热自发）阴弱（汗自出）。
- **啜粥助汗 / 微汗法**：桂枝汤服后啜热稀粥、温覆，取"遍身微似有汗"，不可大汗。

## Mental Models
- **"有汗桂枝、无汗麻黄"**：有汗表虚用桂枝汤，无汗表实用麻黄汤——太阳两大主方的铁律。
- **"取微汗、忌如水流离"**：发汗目标是遍身微微汗出（营卫和），大汗淋漓反"病必不除"。
- **真寒假热 / 真热假寒（条文 11）**：身大热反欲得衣＝热在皮肤、寒在骨髓；身大寒反不欲近衣＝寒在皮肤、热在骨髓。辨真假以"欲不欲近衣"为枢，而非体温本身。
- **发于阳 / 发于阴（条文 7）**：发热恶寒者发于阳，无热恶寒者发于阴——以热之有无分阴阳。

## Anti-patterns
- **误汗 / 误下 / 误吐 / 温针**：表证误用攻下、涌吐、火针等 → 坏病，变证丛生。
- **大汗如水流离**：过汗伤津亡阳，表反不解。
- **酒客与桂枝汤**：酒客不喜甘，得之则呕——桂枝汤之甘草、大枣甘味为禁。
- **脉浮紧、发热、汗不出者误与桂枝汤**：表实无汗反用解肌之桂枝汤，开门揖盗。

## Worked Example（条文 12 · 桂枝汤证全流程）
> 太阳中风，阳浮而阴弱……啬啬恶寒，淅淅恶风，翕翕发热，鼻鸣干呕者，桂枝汤主之。

- 方：桂枝（去皮）三两、芍药三两、甘草（炙）二两、生姜（切）三两、大枣（擘）十二枚。
- 服法：水七升，微火煮取三升，适寒温服一升；服后须臾啜热稀粥一升余以助药力，温覆令一时许，取"遍身微似有汗"为佳；一服汗出即停后服，不必尽剂；不汗则更服、小促其间；病重可日一夜服至二三剂。
- 禁忌：生冷、粘滑、肉面、五辛、酒酪、臭恶等物。

**Why it works**：桂枝汤五药分工——桂枝、生姜辛温散寒解肌，芍药酸收敛阴，甘草、大枣甘温和中，共奏调和营卫、解肌发表之功；啜粥、温覆是"借谷气、助药力"的辅助发汗法。

## Key Takeaways
1. 太阳病 = 表证；"脉浮、头项强痛、恶寒"是定位表的铁律。
2. 有汗（中风/表虚）用桂枝汤，无汗（伤寒/表实）用麻黄汤。
3. 发汗只求"微汗"，大汗则亡阳伤津、病必不除。
4. 误治成坏病时，放弃原方，回到"观其脉证，知犯何逆，随证治之"。
5. 桂枝汤是"群方之首"，其加减类方覆盖汗漏、胸满、项背强、如疟、蓄水等太阳变证。
